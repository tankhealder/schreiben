# Kurrāsa – Arabisch-Schreibheft

Eine kleine Übungs-App zum Schreiben arabischer Schrift mit dem Stift (z. B. Samsung-Tablet mit S Pen).

- **Wörter & Sätze:** Grundwörter, Artikel ال, Pronomen, Besitz-Endungen, weibliche Form mit ة, kurze Sätze
- **Buchstaben:** alle Formen (allein, Anfang, Mitte, Ende) mit Schreibtipps
- **Eigenes Wort:** neue Vokabeln aus dem Kurs eintippen und üben
- Nachfahren oder aus dem Kopf schreiben, danach mit „Vergleichen“ die Vorlage in Rot darüberlegen
- Sanfter Klang und Lob auf Arabisch nach jeder Übung

Alles steckt in `index.html`, ohne Build-Schritt. Über GitHub Pages lässt sich die App im Tablet-Browser öffnen und zum Startbildschirm hinzufügen; danach läuft sie auch offline.
